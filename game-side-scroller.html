PROJECT OVERVIEW / PYTHON + PYGAME

Inside the game.

Pixel Quest: Secret Worlds is a 2D side-scrolling game I developed using Python and Pygame. It combines platform movement with a menu and an overworld, includes a set of ready-made stages, and lets players design their own stages using a level editor. There is also a Secret Mode. The supplied gameplay recording shows the pixel-art menu, player movement and platform world.

HOW TO PLAY ↗

Choose one of the ready-made stages, or create a custom stage with the level editor. Guide the character around the platform world, time your movements, and explore the game’s different modes, including Secret Mode.
