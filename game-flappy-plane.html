PROJECT OVERVIEW / JAVA GAME

Inside the game.

Flappy Plane is a reflex-based Java game. The player guides a small flying character through the gaps between green vertical obstacles against a sky-blue background. The challenge is to keep the character moving without hitting an obstacle.

HOW TO PLAY ↗

Navigate between the obstacles by timing the character's movement. Avoid collisions, keep going through the gaps and try to improve your run.
